# Contributing

1. Open an issue first for big changes.
2. Package list: `config/package-lists/hex.list.chroot`. Files copied into the OS: `config/includes.chroot/`.
3. Run **Actions → Build HEX OS ISO** on your fork to test. The "package names" step fails in about a minute if a name is wrong.
4. Test the ISO in a virtual machine before opening a pull request.
